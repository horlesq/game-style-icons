# Product

## Platform

web

## Stack

Plain static HTML/CSS/JS in the repo root, generated by `gen.py` together with the icons (like `preview.html`), so the page always matches the current icons. Served by GitHub Pages from `main` (repo root), also at the custom domain `icons.horly.dev` (Cloudflare CNAME). Confirmed by the owner 2026-10-10.

## Users

Developers on any stack (React, Vue, Svelte, Angular, plain HTML, server templates) looking for icons with a video-game look for a project (owner-confirmed audience; the owner asked on 2026-10-10 that the set work in any code, not only React). Which projects exactly (indie game sites, launchers, community or streaming tools, game jams) is an inference, not research. Their job on the landing page: find a style that fits, see the icons they need in it, copy the install command or an import, and star the repo.

## Product Purpose

Game Style Icons is an open-source icon set: 100 icons (72 for interfaces, 28 for games) drawn in 50 styles inspired by video games, 5,000 icons shipped four ways: a `<game-icon set name size label>` web component for any framework or plain HTML (also loadable from a CDN), React components (forwardRef, `size` and `title` props; React is an optional peer), functions returning SVG strings, and plain SVG files. TypeScript types for all of it; tree-shakable. Success for the landing page: a visitor who arrives curious leaves with the package installed or an icon copied, and stars the repo.

## Positioning

The same 100 icons exist in every style, built from one glyph set, so changing a whole interface's look is changing an import path (`game-style-icons/cyberpunk` to `game-style-icons/minecraft`). The styles are original drawings in each game's visual language (line, colour, effects), not ripped assets. No icon has a background tile.

## Operating Context

- Install: `npm install github:horlesq/game-style-icons` (not on npm), or no install: `<script type="module" src="https://cdn.jsdelivr.net/gh/horlesq/game-style-icons@v0.4.0/src/element.js">`.
- Web component: `import 'game-style-icons/element'` then `<game-icon set="cyberpunk" name="heart" size="32" label="Lives">`.
- React: `import { CyberpunkHeart } from 'game-style-icons/cyberpunk'` (React 18+). SVG strings: `import { CyberpunkHeart } from 'game-style-icons/html/cyberpunk'`, `CyberpunkHeart({ size: 32 })`.
- Names: style prefix + icon name, identical across React and strings; the web component takes the style slug and kebab icon name.
- Plain SVGs: `svg/<style>/<icon>.svg`; manifest of styles, prefixes, categories and component names: `icons.json`.
- Regenerating: `python3 gen.py` rewrites src/, svg/, icons.json, preview.html, package.json exports and README tables.
- Repo: https://github.com/horlesq/game-style-icons (public since 2026-10-10). MIT licence.

## Capabilities and Constraints

- 50 styles in 6 categories: Neon and glow, Bold cartoon, Pixel and arcade, Ink and paint, Metal stone and dark fantasy, Flat and graphic.
- `portal` and `mirrors-edge` use `currentColor` (follow text colour); some styles change colour per icon (Splatoon, Among Us, Tetris, Fortnite, LittleBigPlanet, Borderlands).
- Pixel styles use their own grids (16, 13 or 12 units).
- Not on npm: never show npm badges, weekly downloads or `npm i game-style-icons` without the GitHub prefix.
- Contains no game logos, characters, fonts or assets; game names are trademarks of their owners, used only to describe styles; not affiliated with or endorsed by any game or publisher. The page must keep that statement and must not use game logos or official artwork.

## Product Principles

1. The icons are the pitch: show many real icons early, in many styles, rather than describing them.
2. One copy away: the install command and any icon's import are copyable in one action.
3. Honest about the state: GitHub install, not on npm, original artwork, not affiliated with the games.
4. Respect the games: borrow a style's visual language, never its logos or assets.
